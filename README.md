# پومکس شیراز

وبسایت نمایندگی رسمی پومکس در شیراز (تولیدکننده چسب کاشی، افزودنی‌های بتن و مواد آب‌بندی) — ساخته‌شده با Next.js (App Router) و MongoDB.

## امکانات

- طراحی اختصاصی با رنگ سازمانی `#0073bc` و سفید، راست‌به‌چپ (RTL)، فونت وزیرمتن و انیمیشن/موشن (framer-motion) روی اسکرول و هاور
- سئوی کامل با کلمات کلیدی چسب کاشی، افزودنی بتن و مواد آب‌بندی: متادیتای پویا برای هر صفحه/محصول/مقاله، `sitemap.xml`، `robots.txt`، داده‌های ساختاریافته Schema.org (LocalBusiness، Product، Article، BreadcrumbList، FAQPage)، تصاویر Open Graph تولید خودکار
- مدیریت محصولات و قیمت‌ها از طریق MongoDB با پنل مدیریت اختصاصی (بدون نیاز به Postman یا دستور جداگانه)
- به‌جای دکمه خرید، دکمه «تماس برای خرید» با لینک مستقیم تماس تلفنی (`tel:`) در همه‌جای سایت + نوار تماس چسبان در موبایل
- صفحه اصلی پر با بخش‌های متعدد: معرفی سه خط تولید (چسب کاشی، افزودنی بتن، آب‌بندی)، آمار زنده از دیتابیس، مراحل خرید، گالری فروشگاه/انبار، و پرسش‌های متداول
- بخش وبلاگ کامل با صفحه لیست، صفحه مقاله، تاریخ شمسی و مقالات مرتبط
- صفحات درباره ما و تماس با ما با نقشه گوگل

## پیش‌نیازها

- Node.js نسخه 18 به بالا
- یک دیتابیس MongoDB (Atlas یا سرور شخصی)

## نصب و راه‌اندازی

```bash
npm install
```

فایل `.env.local` را در ریشه پروژه بساز (نمونه در `.env.example` موجود است) و مقادیر واقعی را وارد کن:

```
MONGODB_URI=...
NEXT_PUBLIC_SITE_URL=https://your-domain.ir
NEXT_PUBLIC_PHONE=0917...
ADMIN_USERNAME=...
ADMIN_PASSWORD=...
ADMIN_SESSION_SECRET=یک-رشته-تصادفی-و-طولانی
```

> **مهم:** فقط در `.env.local` مقدار واقعی بگذار. `.env.example` یک الگوی عمومی است و معمولا در گیت commit می‌شود؛ هرگز رمز واقعی یا رشته اتصال MongoDB را در آن قرار نده.

اجرای نسخه توسعه:

```bash
npm run dev
```

سایت روی [http://localhost:3000](http://localhost:3000) بالا می‌آید.

### افزودن داده نمونه (اختیاری)

برای دیدن سایت با چند محصول و مقاله نمونه:

```bash
npm run seed
```

این دستور چند محصول و مقاله آزمایشی در MongoDB درج می‌کند که می‌توانید بعدا از پنل مدیریت حذف یا ویرایش کنید.

## پنل مدیریت

آدرس: `/admin`

با `ADMIN_USERNAME` و `ADMIN_PASSWORD` که در `.env.local` تعریف کردید وارد شوید. از این پنل می‌توانید:

- محصول جدید اضافه کنید (عنوان، دسته‌بندی، قیمت، قیمت با تخفیف، تصاویر، مشخصات فنی، موجودی)
- مقاله وبلاگ بنویسید و منتشر کنید
- محصولات/مقالات موجود را ویرایش یا حذف کنید

### تصاویر محصولات و مقالات

دو روش برای تصویر وجود دارد:

1. آدرس تصویر از یک سرویس خارجی (مثل یک CDN یا هاست تصویر) را در فیلد مربوطه وارد کنید.
2. اگر روی سرور شخصی (VPS) میزبانی می‌کنید، فایل تصویر را داخل پوشه `public/uploads/` قرار دهید و در فرم فقط مسیر `/uploads/نام-فایل.jpg` را وارد کنید.

### تصاویر فروشگاه و انبار (گالری صفحه اصلی و درباره ما)

بخش گالری به‌صورت خودکار دنبال ۶ فایل مشخص در پوشه `public/gallery/` می‌گردد و تا وقتی فایل واقعی قرار نگیرد، جای خالی آن را با یک placeholder نشان می‌دهد. برای نمایش عکس‌های واقعی، فایل‌ها را با همین نام‌ها در `public/gallery/` قرار دهید:

- `shop-1.jpg` — نمای فروشگاه
- `shop-2.jpg` — نمایش محصولات در فروشگاه
- `warehouse-1.jpg` — انبار مرکزی
- `warehouse-2.jpg` — چیدمان محصولات در انبار
- `delivery.jpg` — آماده‌سازی سفارشات
- `team.jpg` — تیم فنی و مشاوره

می‌توانید نام فایل‌ها یا تعداد آن‌ها را در `src/lib/gallery.ts` تغییر دهید.

## سئو

- عنوان و توضیحات هر محصول/مقاله را در فرم پنل مدیریت (بخش «عنوان سئو» و «توضیحات متا سئو») تکمیل کنید تا در نتایج گوگل نمایش داده شود.
- پس از انتشار سایت، آدرس `https://your-domain.ir/sitemap.xml` را در Google Search Console ثبت کنید.
- مقدار `NEXT_PUBLIC_SITE_URL` را حتما با دامنه نهایی سایت هماهنگ کنید، در غیر این صورت متادیتا و sitemap اشتباه تولید می‌شود.

## دیپلوی (انتشار سایت)

- **Vercel:** ریپازیتوری را به Vercel متصل کنید، متغیرهای محیطی بالا را در تنظیمات پروژه Vercel وارد کنید و دیپلوی کنید.
- **سرور شخصی (VPS):** پس از `npm run build`، با `npm run start` یا از طریق PM2 اجرا کنید و با Nginx به‌عنوان reverse proxy معرفی کنید.

## ساختار پروژه

```
src/
  app/            صفحات (Home, Products, Blog, About, Contact, Admin)
  components/     کامپوننت‌های عمومی UI
  actions/        Server Actions برای ثبت/ویرایش/حذف محصول و مقاله
  models/         مدل‌های Mongoose (Product, BlogPost)
  lib/            اتصال دیتابیس، تنظیمات سایت، توابع کمکی
scripts/seed.ts   اسکریپت درج داده نمونه
```
