# بازطراحی پومکس شیراز

## نقد نسخه پیشین بر اساس کد
- هدر شلوغ با اسلایدر، حباب و نقشه؛ سلسله‌مراتب پیام خرید کم‌رنگ بود.
- کارت‌های مشابه و بخش‌های تکراری، ریتم بصری یکنواخت ایجاد می‌کردند.
- لینک شماره موبایل در بخش تماس فاقد tel بود.
- آمار صفر در قطعی دیتابیس به مخاطب نمایش داده می‌شد.
- متن مقاله فقط به پاراگراف شکسته می‌شد و HTML پومکس پشتیبانی نمی‌شد.
- مقالات مستقل از منبع اصلی بودند.

## اجرا
هدر روشن با تصویر موجود، مسیر انتخاب کاربرد، استایل واکنش‌گرا، حالت فوکوس، کاهش حرکت، تماس قابل کلیک و CTA مقاله اضافه شد. HTML مقاله با sanitize-html پاک‌سازی می‌شود.

## اتصال محتوا
متغیر سروری POMEX_BLOG_MONGODB_URI باید توسط مسئول سرور تنظیم شود؛ یک کاربر MongoDB با نقش read فقط برای pomexlux بسازید. این کد هرگز در دیتابیس منبع نمی‌نویسد. دیتابیس pomexlux و مجموعه blogs عین منبع است. lang=fa و فیلتر انتشار مطابق منبع (published یا legacy بدون publication) خوانده می‌شود. فیلدهای اصلی از جمله publication و editorial حفظ و imageUrl، date و content به نمای سایت نگاشت می‌شوند. صفحات وبلاگ هر ۳۰۰ ثانیه بازاعتبارسنجی می‌شوند. صفحه اصلی هر ۳۶۰۰ ثانیه. بدون متغیر، دیتابیس قدیمی باقی می‌ماند. اعتبار اتصال واقعی بدون اطلاعات سرور قابل تایید نیست.

محتوای یکسان canonical منبع دارد. برای رتبه محلی باید راهنماها و صفحات خدمات مختص شیراز با اطلاعات واقعی، تصاویر پروژه و پاسخ‌های کارشناسی ایجاد شوند. رتبه یا افزایش تماس تضمین نمی‌شود. شماره ثابت، آدرس و ساعات موجود در siteConfig باید پیش از انتشار توسط مالک راستی‌آزمایی شوند.
